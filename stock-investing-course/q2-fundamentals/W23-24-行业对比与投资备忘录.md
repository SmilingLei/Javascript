# W23–24｜行业对比与投资备忘录

**学习目标**：做同业比较；为个股写投资备忘录；按规则把 3–5 只个股纳入模拟盘。

---

## 1. 同业对比框架

选 2–4 家同行业公司，做表：

| 指标 | 公司A | 公司B | 公司C |
|------|-------|-------|-------|
| 收入增速 | | | |
| 毛利率 | | | |
| 净利率 | | | |
| ROE | | | |
| 经营现金流/净利润 | | | |
| 资产负债特征 | | | |
| 估值水平（先记录） | | | |

问自己：市场溢价给谁、是否合理？我是否只是在买“故事最大”的那家？

---

## 2. 投资备忘录最低标准

使用 [投资备忘录模板](../templates/04-投资备忘录.md)。  
没有备忘录 = 不允许买入个股（课程纪律）。

备忘录必须包含：

- 投资命题  
- 关键证据（指向年报）  
- 风险与一票否决  
- 反对意见  
- 仓位上限  

---

## 3. Q2 模拟盘规则升级

| 规则 | 要求 |
|------|------|
| 个股数量 | 3–5 只上限 |
| 单票 | ≤ 20% |
| 总仓位 | ≤ 80% |
| ETF | 仍可作为核心底仓 |
| 买入前置 | 完成一页纸 + 备忘录 |
| 禁止 | 题材无研报式追涨、杠杆 |

建议组合形态：**核心宽基 ETF + 少数能力圈个股**。

---

## 4. Q2 毕业标准

- 能独立指出“利润好看但现金流差”的公司特征，并举你研究过的例子  
- 两家公司年报精读材料齐全  
- 模拟盘个股均有备忘录  
- 通过 [Q2 晋级测验](../assessments/Q2-晋级测验.md)

---

## 5. 作业

1. 提交两份完整研究包（一页纸+风险清单+备忘录）。  
2. 按规则调仓，日记记录。  
3. 升级《投资原则》到 v0.2：加入选股与财报检查条款。

---

## 6. 季度复盘

1. 我是否在能力圈内交易？  
2. 哪一次研究我在“找证据支持买入”而不是求真？  
3. 进入估值季前，我是否仍会把“好公司”自动当成“该买”？
