## 买入检查清单（全部勾选才允许下单）

- [ ] 在能力圈内，能用白话讲清生意  
- [ ] 已完成商业模式一页纸与投资备忘录  
- [ ] 财务无“一票否决”项触发  
- [ ] 估值落在事先定义的“便宜/合理”区间（见估值工作纸）  
- [ ] 单票仓位不超过上限 ____%  
- [ ] 买入后总仓位不超过 ____%  
- [ ] 符合目标资产配置，不是情绪加仓  
- [ ] 已写反对意见  
- [ ] 非杠杆、非借贷资金  
- [ ] 冷静期已过（至少 ____ 小时）  

未勾选项说明（若强行买，记违规）：

## 加仓规则

仅当同时满足：

1. Thesis 仍成立  
2. 价格进入更优惠区间或逻辑强化有新证据  
3. 加仓后仍不超过单票与总仓位上限  
4. 不是为了“摊低成本”而报复性加仓  

## 卖出 / 减仓规则

出现任一项，执行预定动作：

| 触发 | 动作 |
|------|------|
| 一票否决风险出现 | 清仓或大幅减仓 |
| Thesis 证伪 | 退出 |
| 估值进入“贵”档且无更强逻辑 | 减仓至 ____% |
| 需要再平衡（比例漂移） | 按配置表调整 |
| 找到显著更优的风险回报（替换） | 替换并记录 |
| 个人资金期限变化（要用钱） | 优先保生活，不计较点位 |

**禁止的卖出理由**：今天亏了难受；别人说要崩盘但无新证据；仅仅因为短期没涨。
