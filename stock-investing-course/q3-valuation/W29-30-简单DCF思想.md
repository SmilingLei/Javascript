# W29–30｜简单 DCF 思想

**学习目标**：理解折现与增长率假设的敏感性；会做“信封背面”级思考，不追求复杂模型幻觉。

---

## 1. DCF 一句话

> 资产价值 = 未来自由现金流折现到今天的总和（再加期末价值等）

股票贵不贵，本质是：你为未来能拿到的现金（分红或最终退出）付了多少，以及不确定性多大。

---

## 2. 新手只需掌握的三个概念

1. **现金流**：越多越实在越好  
2. **增长**：高增长很诱人，但对终端价值影响巨大，易错  
3. **折现率**：越不确定、利率越高，折现率越高 → 现值越低  

教学结论：**不要假装能精确预测 10 年**；用 DCF 思想做压力测试。

---

## 3. 敏感性：为什么模型可以“要什么结果有什么结果”

练习（定性或极简表）：

- 永续增长率从 2% 改到 4%，价值可能大变  
- 折现率从 9% 改到 11%，价值可能大变  

因此：复杂表格 ≠ 更高真理。倍数法 + 情景思维往往更诚实。

---

## 4. 实用替代：情景三档

对未来 5 年设想：

| 情景 | 增长与利润假设 | 对应你愿付的估值上限 |
|------|----------------|----------------------|
| 悲观 | | |
| 基准 | | |
| 乐观 | | |

只在悲观/基准下仍有安全边际时，才考虑较大仓位。

---

## 5. 案例练习

1. 用白话解释：为何“遥远的高增长”折现后可能不多。  
2. 对一家公司写悲观情景：若增速减半，你的买入价如何调整。  
3. 找出你模型里最脆弱的假设（通常是增长或利润率）。
