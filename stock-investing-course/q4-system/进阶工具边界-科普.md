# 进阶工具边界（科普，不实操）

本页对应计划中“明确不教 / 后置”的内容，帮助你划清能力边界。

## 1. 融资融券

- 本质是借钱放大收益与亏损  
- 可能被强制平仓，把暂时波动变成永久损失  
- **本课程全年禁止实操**

## 2. 期货与期权

- 非线性收益、到期、保证金机制复杂  
- 适合专业风险管理场景，不适合当“杠杆彩票”  
- 本课程只要求：知道它们能放大风险，不纳入作业

## 3. 量化高频

- 依赖数据、工程、交易成本与风控体系  
- 个人投资者常见误区：把回测曲线当未来收益  
- 若未来学习，先补统计与过拟合常识

## 4. 你的正确替代

用：**配置 + 研究 + 估值 + 纪律 + 时间** 叠加期望。  
任何承诺稳赚的复杂工具，默认提高警惕。
