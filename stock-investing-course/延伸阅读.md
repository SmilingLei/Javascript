# 延伸阅读与资源（非荐股）

> 以下为学习方向提示。版本与链接请自行检索权威来源；不构成推荐买卖。

## 规则与披露

- 上海/深圳证券交易所投资者教育材料  
- 巨潮资讯网：年报与公告检索  
- 中国证监会投资者保护相关公开读物  

## 概念进阶（主题）

| 主题 | 阅读方向 |
|------|----------|
| 指数与长赢心态 | 指数基金入门读物 |
| 企业分析 | 商业模式与竞争策略经典 |
| 财报 | 财报分析入门书 + 年报原文 |
| 估值 | 证券分析入门、估值常识 |
| 行为金融 | 认知偏差与投资心理 |
| 风险 | 风险管理与杠杆案例复盘 |

## 课程内强制习惯

1. 年报原文优先于二手解读  
2.  每个结论标注来源页码/公告  
3.  拒绝来路不明的“内幕”与付费荐股社群  

## 明确后置（勿早学实盘）

期货、期权、融资融券、高频量化——仅在手册稳固且有真实需求时，另开专题，并先做风险教育。
