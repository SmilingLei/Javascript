# W11–12｜模拟盘启动与投资原则 v0.1

**学习目标**：建成符合规则的模拟组合；产出可执行的《我的投资原则 v0.1》；通过 Q1 毕业标准。

---

## 1. 模拟盘规则（Q1 强制）

| 规则 | 要求 |
|------|------|
| 可交易标的 | 仅宽基 ETF（大盘/中盘/红利等方向） |
| 禁止 | 个股、题材基金梭哈、杠杆、融资 |
| 总仓位 | ≤ 80%（保留现金感受波动与机会） |
| 记录 | 每笔交易写日记；每周净值与回撤 |
| KPI | 纪律合规率，不以跑赢指数论英雄 |

建议初始组合示例结构（按你的画像改比例）：

- 大盘宽基 ETF：____%  
- 中盘/红利等另一宽基：____%  
- 现金：____%

## 2. 《我的投资原则 v0.1》写作框架

复制到日记，逐条填空：

```text
1. 目标与期限：
2. 最大可承受回撤与应急动作：
3. 目标资产配置：
4. 可投资标的范围（Q1）：
5. 禁止事项：
6. 买入必要条件（至少 3 条）：
7. 卖出/再平衡条件：
8. 技术分析使用边界：
9. 复盘节奏：
10. 本版本日期与下季升级计划：
```

v0.1 不要求完美，要求**可执行、可检查**。

## 3. Q1 毕业标准（对照打分）

| 标准 | 达标？ | 证据 |
|------|--------|------|
| 能解释“为什么大多数人亏钱” | | 300 字短文 |
| 能计算并跟踪最大回撤 | | 净值表 |
| 模拟盘仅 ETF 且纪律完整 | | 交易日志 |
| 完成画像 + 原则 v0.1 | | 文档 |
| 本季无杠杆/无跟风实盘冲动未记录 | | 自检 |

**短文提示（为什么大多数人亏钱）可覆盖：**费用与换手、杠杆、从众追高、缺乏安全边际、把波动当信号、没有配置与期限匹配。

未达标：延长 2–4 周，重做模拟与原则，再进入 Q2。

## 4. 案例练习

1. 假设指数一周下跌 8%，按原则写出你的动作清单。  
2. 朋友推荐“稳赚题材票”，用原则条文拒绝并记录情绪。  
3. 对当前模拟组合做一次“持有理由朗读”（每只 30 秒）。
